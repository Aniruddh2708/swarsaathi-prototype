# User guide

## Prepare for recording

Use a quiet setting with a single singer. Select the microphone route before
starting. Allow microphone access and keep the application in the foreground
during recording.

The input bar indicates sound level. It does not need to fill completely and
does not indicate whether a note is correct.

## Find my Sa

1. Record a comfortable low vowel without forcing the voice.
2. Record a comfortable middle vowel.
3. Record a comfortable high vowel.
4. Review the suggested Sa. Use **Listen to Sa** if helpful.
5. Use **Adjust Sa** if needed, then select **Confirm this Sa**.

Hold each vowel steadily for a few seconds. A brief fluctuation does not end a
recording immediately. If the application cannot obtain a consistent sample,
record that sample again.

Listening to the reference is optional; confirmation is required. A new recording
or a manual adjustment requires confirmation again.

## Choose an exercise

Select **Sa Re Ga Re Sa** or **Basic Ascent & Descent**, then choose a tempo
between 40 and 120 BPM. Each note lasts one beat.

The confirmed Sa stays fixed when the exercise changes. If an exercise extends
beyond the recorded range, choose another exercise or return to adjust and
reconfirm Sa.

## Listen to the reference

**Listen first** plays a generated reference melody using the selected targets
and tempo. Playback can be stopped at any time and is not required before
practice. Starting practice stops reference playback before opening the
microphone.

## Practise

1. Select **Start Practice**.
2. Wait for the visual three-beat count-in.
3. Sing one note per beat while following the guide.
4. Continue through mistakes; the scheduled targets advance with time.

The purple guide shows the expected notes. The blue line shows measured voice
pitch. Time runs from left to right, and higher notes appear higher on the graph.
Gaps indicate that no reliable pitch was available.

If recording is interrupted or the microphone connection changes, begin a fresh
attempt. The application does not silently join separate recordings.

## Read the results

**Pitch match** summarizes the complete scheduled exercise. Individual note
cards show the result for each swar. Wrong notes, missing voice, and unreliable
input reduce the percentage.

The main metric allows brief adjacent-note transitions. Under **Details**, the
result without that transition allowance and the proportion of reliable voice
are available separately. The percentage describes this exercise at the selected
tempo; it does not assess expression, breath control, or overall musicianship.

Select **Practice Again** to begin a fresh attempt.

## Share a report

Use **Details → Share report** to export the current result. The report contains
numerical pitch observations, timing, scoring settings, and results. It does not
contain the original microphone recording. Reports are stored locally and are
shared only through the explicit share action.
